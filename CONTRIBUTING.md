# Contributing to Skytrace

Open an issue with the steps to reproduce the problem, what you expected, and the browser and operating system you used. For an aircraft or map issue, include the approximate time in UTC and the region or flight callsign if relevant.

For a pull request, use the [local setup in the README](README.md#run-locally). Keep each change focused, run `npm run build`, and check any UI or data behavior the change affects. Describe what changed and how you verified it in the pull request.

If you add an asset or data source, include its origin, license, and required attribution in the [third-party notices](THIRD_PARTY_NOTICES.md). Keep API credentials out of commits, issues, screenshots, and logs.
